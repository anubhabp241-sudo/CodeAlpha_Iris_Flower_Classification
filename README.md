# CodeAlpha_Iris_Flower_Classification
# Iris Flower Classification

## Project Overview

This project is completed as part of the CodeAlpha Data Science Internship.

The objective of this project is to build a machine learning classification model that predicts the species of an Iris flower based on its sepal and petal measurements.

## Dataset

The dataset contains measurements of Iris flowers belonging to three species:

- Iris-setosa
- Iris-versicolor
- Iris-virginica

### Features

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

### Target

- Species

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Model

A Decision Tree Classifier is used for classification.

## Methodology

1. Load the dataset
2. Explore the data
3. Check for missing values
4. Visualize the dataset
5. Separate features and target
6. Split the dataset into training and testing sets
7. Train the Decision Tree model
8. Make predictions
9. Evaluate the model
10. Visualize the confusion matrix

## Evaluation

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Conclusion

The trained machine learning model successfully classifies Iris flowers into their respective species based on their sepal and petal measurements.
